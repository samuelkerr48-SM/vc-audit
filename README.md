# VC Curriculum Audit

**Open the tool:** https://samuelkerr48-sm.github.io/vc-audit/

Audit a school's teaching sequences against **Victorian Curriculum F–10 Version 2.0**. Upload unit plans, term plans, yearly overviews or a VCAA curriculum area map, and see which content descriptions are covered, which are missing and what to look for when planning the gaps.

- Every learning area except Languages, from a single level to a whole school
- Reads Word, PDF, PowerPoint, Excel and CSV files, and VCAA curriculum area maps (Word)
- Progression across levels, achievement standards, when in the year, and a curriculum area map check
- Word report, Excel gap action plan and one-page team summaries

**Private:** files are read in the browser. Nothing is uploaded or sent anywhere, and no AI is used. Work is kept in the browser until a new audit is started.

To use it offline, save `index.html` and open it in Chrome or Edge.
